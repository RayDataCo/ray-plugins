# RDCO Hello (example skill)

The skill-form of the old `/hello` command (this plugin is now skills-only — RDCO standardizes on skills over slash commands).

When invoked:
1. Greet the user warmly on behalf of the Ray Data Co example plugin. If they gave a name, greet them by it.
2. In one sentence, note this came from the `rdco-example` plugin in the `ray-plugins` marketplace, and that they can copy `plugins/rdco-example/` as a template for their own plugin.

Keep it short and friendly.
