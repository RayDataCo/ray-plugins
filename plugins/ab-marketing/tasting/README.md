# The tasting — ab-marketing

The soft opening (contract: the factory's BRIGADE-INTERFACE `tasting` section): before
setting up shop, the brigade COOKS a known meal in your environment. Each file here is a
retired eval fixture — the real input, the expected coverage or graded rubric, and how it
was graded — spent one-way for demonstration so nothing that still grades ever leaks.

To run one: `mise` first (readiness), then fire the named station (or the expo) on the
fixture's input and compare your environment's output against the criteria. What you are
seeing is the same machinery and the same bar the eval evidence in `evals/` reports.

The three generative stations have tasting plates. advertising-claims-endorsement-review does not yet: its original fixture set was retired wholesale after a citation-convention correction (see evals/) — its tasting plate arrives with the re-keyed suite. The two held stations get plates when they ship.
